# iOSRealRun 0.2.0-beta.1

这是项目的首个桌面预发布版本。原来的命令行入口继续保留，新增的界面可以完成设备连接、选取路线和回放控制。

## 下载

- **Windows x64**：下载 `iOSRealRun-Windows-x64.zip`，完整解压后打开 `iOSRealRun.exe`。
- **macOS 15+ / Apple Silicon（实验）**：下载 `iOSRealRun-macOS-arm64.zip`，解压得到 `.app`。尚无 Developer ID 签名及公证，也未提供 Intel 构建。
- **Ubuntu 22.04 / 24.04 x64（实验）**：下载 `iOSRealRun-Linux-x64.tar.gz`。需要桌面环境、Qt 系统库与 `usbmuxd`，具体命令见 README。

压缩包自带运行环境和六条示例路线，无需另装 Python。`SHA256SUMS.txt` 可用于校验下载结果。

## 本次更新

- 项目统一命名为 iOSRealRun。
- 重做 Qt 桌面界面，统一圆角控件、字体和路线预览，坐标设置默认折叠。
- 支持地图选点、TXT / JSON / GPX 导入、坐标粘贴以及 BD-09 / GCJ-02 / WGS 84 转换。
- 支持开放和闭合路线、速度及圈数设置、暂停、继续、停止和恢复定位。
- 记住最近使用的路线；内置紫金港东操场、西操场、玉泉两条路线、西溪和海宁路线。
- 改善设备连接取消、退出时的定位清理、多设备选择以及地图缓存损坏处理。
- Windows 源码启动器可检测并重建失效虚拟环境；个人配置不随安装包发布。
- 增加自动化测试、跨平台打包、使用说明和问题反馈表单。

## 兼容性与已知限制

**兼容 iOS 26、27 和 iPadOS 26.4。** 通过 USB 连接设备，确认信任电脑并开启开发者模式即可使用。

iOS / iPadOS 17.0–17.3 暂不支持直接使用；14–16 保留命令行路径，需要开发者磁盘镜像。macOS 和 Linux 安装包属于实验构建，构建和界面自检不等同于 USB 真机验证。

正常停止时会尝试恢复定位。设备断开或服务无响应时，可能需要重新连接并点击「恢复定位」。地图底图依赖 OpenStreetMap 在线服务；导入文件和使用预置路线不依赖在线地图。
