## 开始使用

1. 用 USB 连接设备，解锁并确认「信任这台电脑」，开启「开发者模式」。Windows 需先安装 Apple Devices 或 iTunes。
2. 选择预置路线、在地图上绘制路线，或导入 TXT / JSON / GPX 文件。
3. 设置速度，点击「开始模拟」。可随时暂停或停止；定位未恢复时，保持连接并点击「恢复定位」。
