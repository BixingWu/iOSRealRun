本版新增 **iOS 14–16 的桌面 USB 连接**，修复 iOS 15.6 被提示需要改用命令行、无法点击「开始模拟」的问题。保留 iOS 17.4 及以上的原有连接方式，包括 iOS 26、27 和 iPadOS 26.4。

## 本次更新

- iOS 14 / 15 可直接通过界面开始模拟，不再要求开启这些系统没有的开发者模式开关。iOS 16 仍需开发者模式。
- 开始模拟或恢复定位时，自动检查并挂载匹配的本地开发者镜像；已挂载时直接复用，无需输入命令行。
- 旧系统接入现有的暂停、继续、停止和恢复定位操作，准备镜像期间也可停止；缺少镜像时会显示文件放置目录。
- 新增旧系统版本判断、镜像匹配、连接清理和界面入口等回归测试。详细代码见 [PR #34](https://github.com/BixingWu/iOSRealRun/pull/34)。

## iOS 14–16 使用方法

Release 安装包不内置 Apple 开发者镜像。先准备与设备系统匹配的 `DeveloperDiskImage.dmg` 和 `DeveloperDiskImage.dmg.signature`，可使用已有旧版工具中的镜像。

Windows 以 iOS 15.6 为例，将两个文件放到程序旁的 `DeveloperDiskImage/15.6/` 目录。连接并解锁手机、确认信任后，选择路线并点击「开始模拟」，程序会自动挂载镜像。**iOS 15.6 不需要开发者模式开关。**

其他平台的镜像目录及完整步骤见 [旧版系统说明](https://github.com/BixingWu/iOSRealRun/blob/v0.2.0-beta.4/docs/usage.md#ios-14-16-桌面连接)。Windows 仍需先安装 Apple Devices 或 iTunes 驱动。

## 验证范围

- Windows + iOS 15.6 已获得用户真机试用可用反馈。暂停、停止后定位恢复和异常场景尚未逐项记录验证结果；其他旧系统版本仍待真机回归。
- 自动化测试覆盖版本判断、镜像选择、挂载中停止、定位恢复及新版系统连接流程；模拟设备测试不等同于各版本真机验证。
- iOS / iPadOS 17.0–17.3 仍不支持。
- macOS、Linux 为实验构建，尚未完成 USB 真机回放验证。macOS 应用未签名和公证；Linux 需要桌面环境、`usbmuxd` 和 Qt 系统库，见 [环境配置](https://github.com/BixingWu/iOSRealRun/blob/v0.2.0-beta.4/docs/usage.md#电脑环境)。
